# 常見問題

Echophrase 最常見問題的快速修復方法。

## 轉錄無法運作

<AccordionGroup>
  <Accordion title="說話後沒有出現文字">
    1. 在設定 → 音訊中確認已選擇您的麥克風
    2. 確保 Echophrase 具有麥克風權限
    3. 嘗試提高音量或靠近麥克風
  </Accordion>

  <Accordion title="偵測到錯誤的語言">
    1. 開啟設定 → 語言
    2. 明確設定您偏好的語言
    3. 如果自動偵測造成問題，請停用它
  </Accordion>

  <Accordion title="轉錄速度很慢">
    1. 改用較小的 **Parakeet Lite** 模型
    2. 確認「設定 → GPU 加速」中的 GPU 加速已啟用
       （Windows 上為 DirectML，Apple Silicon 上為 Metal）
    3. 關閉其他高資源消耗的應用程式
  </Accordion>
</AccordionGroup>

## 應用程式問題

<AccordionGroup>
  <Accordion title="Echophrase 無法啟動">
    1. 確認它是否已在系統匣中執行
    2. 嘗試以系統管理員身分執行（Windows）
    3. 在設定 → 進階 → 日誌中查看記錄
  </Accordion>

  <Accordion title="快捷鍵無法使用">
    1. 確保 Echophrase 正在執行（查看系統匣）
    2. 檢查是否與其他應用程式衝突
    3. 嘗試在設定中將快捷鍵重設為預設值
  </Accordion>
</AccordionGroup>
