# GPU 疑難排解

GPU 加速問題的解決方案。

## GPU 未偵測到

Echophrase 會在執行時自動偵測最快的可用 GPU。如果「設定 > GPU 加速」在
有相容 GPU 的機器上顯示「Using CPU」，請按以下步驟檢查。

### 檢查 NVIDIA 驅動程式

```bash
# Windows (PowerShell) 和 Linux/WSL
nvidia-smi
```

如果此指令失敗，請安裝或更新您的 NVIDIA 驅動程式（CUDA 12 需要驅動程式
525 或更新版本）。

### 驗證 CUDA 安裝

```bash
nvcc --version
```

預期輸出應顯示 **CUDA 12.8 或更新版本**。更早的版本已不再相容於內建的
ONNX Runtime。

### 檢查 cuDNN

您的系統上必須安裝 cuDNN 9.19 或更新版本。最簡單的安裝方式：

**Ubuntu/Debian：**
```bash
sudo apt install libcudnn9-cuda-12
```

**Windows：**
1. 從 [NVIDIA 下載 cuDNN 9.19+](https://developer.nvidia.com/cudnn)
   （需要免費的開發者帳戶）
2. 執行安裝程式 - 它會自動與您現有的 CUDA Toolkit 整合

**在 Linux 上驗證：**
```bash
ldconfig -p | grep cudnn
# 應列出 libcudnn.so.9
```

安裝或升級 cuDNN 後請重新啟動 Echophrase。

## GPU 已偵測但未使用

開啟「**設定 > GPU 加速**」並確認：

1. 已選擇「**自動（推薦）**」- 這讓 Echophrase 在工作階段開始時選擇最快的裝置
2. 頂部的內嵌狀態顯示您的 GPU（例如：「目前使用：Using CUDA
   (NVIDIA GeForce RTX 3090)」）

如果安裝了相容的 GPU 但狀態仍顯示「Using CPU」，則表示內建的 ONNX Runtime
無法在執行時找到 CUDA 函式庫。通常是因為：

- 您的驅動程式版本比 CUDA toolkit 主要版本舊
- cuDNN 缺失或版本比 9.19 舊
- 您有多個 CUDA 版本安裝而錯誤的版本處於使用中

## 記憶體不足錯誤

如果您看到「CUDA out of memory」：

1. 使用較小的模型（Tiny 或 Base）
2. 關閉其他 GPU 密集型應用程式
3. 重新啟動 Echophrase 以釋放 GPU 記憶體

## 效能問題

如果 GPU 轉錄速度很慢：

1. 在轉錄期間使用 `nvidia-smi` 檢查 GPU 使用率
2. 確保沒有發生熱節流
3. 嘗試使用較小的模型以獲得更快的結果
