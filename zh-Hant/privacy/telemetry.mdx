Echophrase 會在首次啟動時詢問是否傳送匿名使用統計，該選項預設為勾選。本頁完整列出勾選後會傳送的所有內容。這裡沒有任何省略：若某個事件未列於本頁，應用程式就不會傳送它。

  沒有例外。關閉此設定後，Echophrase 什麼都不會傳送 - 連安裝數統計也不會。您選擇退出後唯一離開您裝置的，是一個 `telemetry_disabled` 通知，讓我們的儀表板停止將您計為活躍使用者。

## 如何關閉

「**設定 > 資料 > 傳送匿名使用統計**」- 一個開關，沒有確認彈窗，立即生效。

偏好使用環境變數？Echophrase 在啟動時會遵守下列任一變數，且優先於設定值：

```bash
DO_NOT_TRACK=1 echophrase          # 跨廠商通用慣例
ECHOPHRASE_NO_TELEMETRY=1 echophrase   # 我們自己的變數，若您想更明確
```

設定任一變數啟動時不會傳送任何資料，**且**不會消耗一次性的首次啟動標記，因此之後的正常啟動仍會被正確計數。

開發版建置（`bun run tauri:dev`）完全不會傳送遙測。

## 事件清單

事件會先在本機排入佇列，僅在應用程式閒置時（距離上次錄音或轉錄至少 10 分鐘）、儲存設定時，以及應用程式結束時分批傳送。Echophrase 絕不會在轉錄期間或剛結束時發出遙測請求。每個事件只有幾百位元組的中介資料。

| 事件 | 屬性 | 何時傳送 |
|-------|-----------|------|
| `first_launch` | `arch`（x86_64/aarch64） | 機器上首次啟動，在您回答同意選項後（一生一次，以本機標記檔記錄） |
| `app_updated` | `from`、`to`（版本字串） | 更新後的首次啟動 |
| `daily_active` | `auth_state`（pre_login/authenticated）、`recording_mode`（push_to_talk/open_mic）、`arch` | 應用程式啟動，每 24 小時最多一次 |
| `gpu_backend` | `backend`（cuda/directml/cpu/metal）、`vram_bucket`（&lt;4GB/4-8GB/8-16GB/&gt;16GB/unknown） | 每次工作階段的首次轉錄 |
| `transcription_completed` | `model`、`transform_used`、`auth_state`、`paste_at_cursor`、`remove_filler_words`、`gpu_backend`、`processing_ms` | 轉錄完成後 |
| `transcription_failed` | `model`、`gpu_backend`、`error_category`（分類代碼，絕不含原始錯誤字串） | 轉錄失敗時 |
| `model_changed` | `model`（例如「distil-large-v3」） | 您儲存模型選擇時 |
| `settings_saved` | `output_to`、`recording_mode`、`remove_filler_words`、`use_numeric_digits`、`transform_enabled`、`language` | 您變更上述設定時 |
| `pro_modal_shown` | _(無)_ | 顯示 Pro 升級視窗（每工作階段一次） |
| `login_intent` | _(無)_ | 顯示登入視窗（每工作階段一次） |
| `purchase_intent` | `source`（upgrade_modal）、`channel`（固定為「app」） | 您點擊升級按鈕（每來源每工作階段一次） |
| `app_panic` | `location`（相對於原始碼庫的 `src/foo.rs:42`）、`thread`（執行緒名稱） | 應用程式崩潰時（僅正式版建置） |
| `telemetry_disabled` | _(無)_ | 您選擇退出 - 追蹤停止前的最後一個通知 |

### 自動附帶的系統屬性

用戶端會為上述每個事件自動附上：

- 平台與作業系統版本
- 應用程式版本
- 語言地區

以上就是全部。沒有裝置 ID、沒有安裝 ID，也沒有能跨重啟存續的工作階段 ID。

## 絕不收集的資料

| 資料 | 是否收集？ |
|------|-----------|
| 語音錄音 | **從不** |
| 轉錄文字 | **從不** |
| AI 模型的輸入或輸出 | **從不** |
| 崩潰／錯誤訊息 | **從不**（只有原始碼位置） |
| 使用者 ID、安裝 ID、裝置指紋 | **從不** |
| IP 位址 | **從不儲存**（我們的 Aptabase 執行個體不保留） |
| 錄音長度或頻率 | **從不**（`processing_ms` 是模型運算時間，不是您說話的時長） |
| Cookie | **無** |

## 資料傳送到哪裡

- **後端**：[Aptabase](https://github.com/aptabase/aptabase)，自架於 `https://telemetry.echophrase.com` - 資料不會流向第三方分析廠商
- **傳輸**：僅使用 HTTPS（TLS 1.3）
- **保留期限**：原始事件於一年後刪除
- **原始碼**：桌面應用程式的 `src-tauri/src/telemetry/` - 上表與實際傳送事件的程式碼同源

## 您的帳號資料是分開的

以上全部都是匿名且未與帳號連結。若您登入，與帳號相關的資料（電子郵件、訂閱方案、轉錄次數）受「**設定 > 資料**」中的自助 GDPR 功能保障：**取得資料**可匯出我們持有的全部內容，**刪除（匿名化）帳號**則可將其移除。

概觀請見[隱私與資料](/zh-Hant/privacy)，資料保留、第三方處理者及您的 GDPR/CCPA 權利詳情請見完整的[隱私政策](https://echophrase.com/privacy)。
