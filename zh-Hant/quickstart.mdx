# 快速入門

只需幾個步驟，即可在您的電腦上啟動 Echophrase。無需註冊 - 免費方案首次啟動即可無限使用，且 100% 離線。

## 1. 下載與安裝

從[下載頁面](/zh-Hant/download)下載適用於您平台的最新版本。

## 2. 啟動 Echophrase

從應用程式選單開啟 Echophrase。首次啟動時，它會下載 AI 模型（約 150MB）。

## 3. 授予麥克風存取權限

系統提示時，請允許 Echophrase 存取您的麥克風。您的音訊會在本地處理 - 不會傳送到雲端。

## 4. 開始轉錄

1. 在任何文字欄位中點擊（瀏覽器、編輯器、聊天軟體）
2. 按住錄音快捷鍵 - 在 Windows/Linux 上為 **Ctrl+Shift+Space**，在 macOS 上為**聽寫鍵**（麥克風圖示，F5）
3. 自然說話
4. 放開按鍵 - 您的話語會以文字形式出現

就這麼簡單！您已準備就緒。
