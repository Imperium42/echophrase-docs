# GPU 加速

Echophrase 使用 ONNX Runtime 的自動裝置選擇功能，在執行時選擇最快的可用硬體
進行轉錄。**您無需進行任何設定** - 應用程式會在首次啟動時偵測您的 GPU 並
自動使用它。

## 支援的硬體

| 平台 | 預設加速器 | 所需條件 |
|------|---------|---------|
| **Windows** | DirectML | 任何 DirectX 12 GPU（NVIDIA、AMD、Intel）- 已隨附，無需安裝 |
| **Windows（Copilot+ PC）** | NPU | Snapdragon X 或 Intel Core Ultra - 自動選擇 |
| **macOS** | CoreML（Metal） | Apple Silicon（M1+），macOS 13.3+ |
| **Linux / WSL** | CPU | 社群支援，需從原始碼建置 |

## 為什麼沒有 CUDA？

Windows 上預設使用 DirectML，因為應用程式已隨附它（DirectML 1.15.4），可在所有現代 GPU 上執行
（不分品牌），無需對齊驅動程式與 Toolkit 版本。Echophrase 完全不使用 CUDA，
您也不需要 CUDA Toolkit 或 cuDNN。NVIDIA GPU 在 Windows 上由 DirectML 完整支援。

Linux 版本僅支援 CPU。

## 驗證 GPU 使用

1. 開啟 Echophrase 設定
2. 查看 **GPU 加速** - 最上方會顯示目前使用的裝置
   （例如：「目前使用：Using DirectML (NVIDIA GeForce RTX 3080)」）
3. 轉錄一個片段並確認轉錄速度很快

如果目前使用的裝置顯示「Using CPU」但您有安裝 DirectX 12 GPU，請查看
[GPU 疑難排解](/zh-Hant/troubleshooting/gpu)。

## 疑難排解

如果 GPU 加速無法運作：

- 將顯示卡驅動程式更新至供應商提供的最新版本（NVIDIA / AMD / Intel）
- 確認您的 GPU 支援 DirectX 12（大多數 2015 年後推出的顯示卡都支援）
- 查看 [GPU 疑難排解](/zh-Hant/troubleshooting/gpu) 以獲得特定平台的協助
