# 模型選擇

Echophrase 使用 OpenAI 的 Whisper 模型。選擇最適合您需求的模型。

## 可用模型

| 模型 | 大小 | 速度 | 準確度 | 最適合 |
|------|------|------|--------|--------|
| **Tiny** | ~75 MB | 最快 | 良好 | 快速筆記、低階硬體 |
| **Base** | ~150 MB | 快速 | 較好 | 日常使用、均衡 |
| **Small** | ~500 MB | 中等 | 很好 | 專業使用 |
| **Medium** | ~1.5 GB | 較慢 | 優秀 | 高準確度需求 |
| **Large** | ~3 GB | 最慢 | 最佳 | 最高準確度 |

## 建議

- **僅 CPU**：從 Tiny 或 Base 開始
- **NVIDIA GPU**：Base 或 Small 達到最佳平衡
- **高階 GPU**：Medium 或 Large 獲得最高準確度

## 更換模型

1. 開啟 Echophrase 設定
2. 前往 **AI 模型**
3. 選擇您偏好的模型
4. 等待下載完成（約 1-2 分鐘）

<Note>
模型只需下載一次，並會在本地快取。在已下載的模型之間切換是即時的。
</Note>
