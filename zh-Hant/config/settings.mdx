# 設定

從主視窗的齒輪圖示開啟設定。設定分為以下幾個區塊。

## 帳號

登入完全是可選的，僅在需要 Pro 功能時才需要 - 免費方案在完全離線的情況下也能正常使用，無需帳號。若您選擇登入，可檢視您的電子郵件、已連結的提供者（Google、email）以及目前的方案等級。您可以輸入授權金鑰、連結其他登入方式，或登出。

## 音訊輸入

選擇您的麥克風輸入裝置，並調整**語音閾值**（0–100%）以決定何時偵測到語音。使用**測試**按鈕查看即時音量計。

## 錄音

- **最長持續時間**：每次錄音 5–60 秒（所有方案皆同）
- **移除填充詞**：過濾「嗯」、「啊」等語助詞 <sup>Pro</sup>
- **數字正規化**：將「三」轉換為「3」 <sup>Pro</sup>
- **為未完成的句子附加空格**：當轉錄文字未以 `.`、`!` 或 `?` 結尾時附加一個尾隨空格，讓你可以在句子中途暫停並繼續聽寫，而不必手動加空格（預設開啟）

## 快捷鍵

設定切換錄音的全域快捷鍵。預設：在 Windows/Linux 上為 **Ctrl+Shift+Space**，在 macOS 上為**聽寫鍵**（麥克風圖示，顯示為 F5）。點擊綁定進入擷取模式，然後按下您想要的組合鍵。ESC 取消。

<Note>當應用程式視窗處於焦點時，ESC 和空白鍵也可作為錄音切換鍵。</Note>

## 語音模型

檢視和更換使用中的轉錄模型。顯示您的 GPU/裝置資訊、目前模型名稱、大小和品質評等。點擊**更換**以瀏覽和下載其他模型。

<Note>可用模型取決於您的方案等級。請參閱 [Beta 頁面](/zh-Hant/beta)的比較表。</Note>

## 自訂模型 <sup>Pro</sup>

自帶您自己的 ONNX 轉錄模型 - 匯入本機的 `.onnx` 檔案，或直接從 HuggingFace 倉庫網址下載。Echophrase 會在切換前驗證模型。支援的格式與模型來源請參閱[自訂模型](/zh-Hant/features/custom-models)。

## 轉換模型 <sup>Pro</sup>

啟用可選的後處理步驟，對轉錄結果進行文法與標點校正。使用輕量級的 **T5-Mini Grammar** 模型（約 60 MB），依需求下載並完全在裝置上執行。此為 **Pro 專屬**功能，免費方案的開關為鎖定狀態。您可以撰寫自訂轉換規則，或使用預設的文法校正。

## GPU 加速

Echophrase 會在執行時自動偵測最快的可用執行提供者。**自動（推薦）**選項
會為您的硬體選擇最佳裝置：任何 Windows DirectX 12 GPU 上的 DirectML、
Apple Silicon 上的 CoreML，或 Copilot+ PC 上的 NPU。當沒有
其他選項可用時，CPU 是後備方案。

如有需要，您可以強制使用特定的提供者：

- **自動（推薦）**：讓 Echophrase 在工作階段開始時選擇最快的裝置
- **DirectML**：強制使用 Windows DirectML（任何 DirectX 12 GPU）
- **CoreML**：強制使用 Apple Metal（Apple Silicon 上的 macOS 13.3+）
- **CUDA**（Windows、NVIDIA、選用）：下載 CUDA 外掛並強制使用 CUDA 提供者 - 需要 CUDA Toolkit 13.0+ 與 cuDNN 9.19+，並須重新啟動
- **CPU**：強制使用 CPU - 適合節省電力或 GPU 忙於其他工作時

<Note>DirectML 在 Windows 上涵蓋 NVIDIA GPU，無需手動對齊驅動程式 /
Toolkit 版本，因此為預設值。已安裝 CUDA 13.0+ 與 cuDNN 9.19+ 的 NVIDIA
使用者，可在此選擇下載並啟用 CUDA 外掛。詳見
[GPU 加速](/zh-Hant/config/gpu)。</Note>

<Note>變更使用中的提供者需要重新啟動 Echophrase 才會生效。當變更需要重新啟動時，設定介面會顯示「重新啟動以套用」橫幅。</Note>

## 輸出

控制轉錄完成後的行為。

- **格式**：純文字（所有方案）、帶自訂中繼資料範本的 JSON <sup>Pro</sup>
- **錄音後動作**（可選擇一或多項）：
  - 複製到剪貼簿（預設）
  - 貼在游標處 <sup>Pro</sup>
  - 儲存為檔案 <sup>Pro</sup> - 設定自動儲存目錄並匯出轉錄結果，包括帶自訂中繼資料的 JSON <sup>Pro</sup>

## 語言

選擇 UI 語言。目前支援：**英語**和**繁體中文**。

## 自訂

切換 UI 元素的可見性 <sup>Pro</sup>：

- 快捷鍵設定
- 轉錄預覽
- 輸出確認（提示通知）
- 複製上次按鈕
- 輸入（麥克風）選擇器
- 模型切換器
- 轉錄速度顯示

## 無障礙

依照您的偏好縮放整個介面 - 適合高 DPI 顯示器，或預設字體太小難以閱讀時使用。

- **介面縮放 - 自動**（預設）：跟隨作業系統的顯示縮放設定（例如 Windows 的 150% 縮放）
- **介面縮放 - 手動**：使用滑桿設定 **50% 到 200%** 之間的任何比例，變更即時套用
- **隨視窗大小縮放介面**：可選擇在調整視窗大小時同步縮放介面

<Note>在少數無法可靠偵測系統縮放的環境中，自動模式會回退到 100%，應用程式會建議切換至手動模式。</Note>

## 雲端同步 <sup>Pro</sup>

可依裝置選擇性啟用，將應用程式設定同步至我們的伺服器，讓設定跟著您在每一台登入的
裝置上。預設為關閉。僅同步設定 - 語音資料、音訊與轉錄內容永不同步，API 金鑰、
硬體設定與本機檔案路徑也不會同步。您可隨時將本機設定上傳，或把伺服器上的版本拉下來。

## MCP 伺服器 <sup>Pro</sup>

啟用此開關，讓 AI 代理（例如 Claude Code）可以透過
[CLI 的 MCP 伺服器](/zh-Hant/mcp)模式操作 Echophrase 的錄音與轉錄功能。
預設關閉，需要有效的 Pro 訂閱。桌面應用程式必須在整個代理工作階段中保持執行，
因為它擁有已載入的轉錄模型。完整的工具清單與設定方式請參閱
[CLI](/zh-Hant/cli) 與 [MCP 伺服器](/zh-Hant/mcp)。

## 資料

- **傳送匿名應用程式統計**：切換匿名當機報告和使用統計（永不收集音訊或文字）。首次啟動時詢問，預設勾選；每個事件都遵守此設定，`DO_NOT_TRACK=1` 則會覆寫它。詳見[我們收集哪些資料](/zh-Hant/privacy/telemetry)
- **取得資料**：GDPR 資料匯出（每 30 天一次）
- **刪除帳號**：匿名化您的帳號資料並登出
- **法律**：服務條款和隱私政策連結
