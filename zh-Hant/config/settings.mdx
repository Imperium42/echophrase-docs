# 設定

從主視窗的齒輪圖示開啟設定。設定分為以下幾個區塊。

## 語言

選擇 UI 語言。目前支援：**英語**和**繁體中文**。

## 帳號

檢視您的電子郵件、已連結的提供者（Google、email）以及目前的方案等級。您可以輸入授權金鑰、連結其他登入方式，或登出。

## 語音模型

檢視和更換使用中的轉錄模型。顯示您的 GPU/裝置資訊、目前模型名稱、大小和品質評等。點擊**更換**以瀏覽和下載其他模型。

<Note>可用模型取決於您的方案等級。請參閱 [Beta 頁面](/zh-Hant/beta)的比較表。</Note>

## GPU 加速

Echophrase 會在執行時自動偵測最快的可用執行提供者。**自動（推薦）**選項
會為您的硬體選擇最佳裝置：任何 Windows DirectX 12 GPU 上的 DirectML、
Apple Silicon 上的 CoreML *（測試中）*，或 Copilot+ PC 上的 NPU。當沒有
其他選項可用時，CPU 是後備方案。

如有需要，您可以強制使用特定的提供者：

- **自動（推薦）**：讓 Echophrase 在工作階段開始時選擇最快的裝置
- **DirectML**：強制使用 Windows DirectML（任何 DirectX 12 GPU）
- **CoreML**：強制使用 Apple Metal（Apple Silicon 上的 macOS 13.3+ — *測試中*）
- **CPU**：強制使用 CPU — 適合節省電力或 GPU 忙於其他工作時

<Note>CUDA 支援已被移除；DirectML 在 Windows 上涵蓋 NVIDIA GPU，無需手動
對齊驅動程式 / Toolkit 版本。詳細原因請參閱
[GPU 加速](/zh-Hant/config/gpu)。</Note>

<Note>變更使用中的提供者需要重新啟動 Echophrase 才會生效。當變更需要重新啟動時，設定介面會顯示「重新啟動以套用」橫幅。</Note>

## 轉換模型

啟用可選的後處理步驟，對轉錄結果進行文法校正。使用輕量級 T5 模型（約 35 MB）。您可以撰寫自訂轉換規則，或使用預設的文法校正。

## 輸出

控制轉錄完成後的行為。

- **格式**：純文字（所有方案）、Markdown（已驗證使用者）、帶自訂中繼資料範本的 JSON <sup>Pro</sup>
- **錄音後動作**（可選擇一或多項）：
  - 複製到剪貼簿（預設）
  - 貼在游標處 <sup>Pro</sup>
  - 儲存為檔案 <sup>Pro</sup> - 設定自動儲存目錄

## 音訊輸入

選擇您的麥克風輸入裝置，並調整**語音閾值**（0–100%）以決定何時偵測到語音。使用**測試**按鈕查看即時音量計。

## 錄音

- **最長持續時間**：每次錄音 5–60 秒（取決於方案等級）
- **移除填充詞**：過濾「嗯」、「啊」等語助詞 <sup>Pro</sup>
- **數字正規化**：將「三」轉換為「3」 <sup>Pro</sup>

## 快捷鍵

設定切換錄音的全域快捷鍵。預設：**Ctrl+Shift+R**。點擊綁定進入擷取模式，然後按下您想要的組合鍵。ESC 取消。

<Note>當應用程式視窗處於焦點時，ESC 和空白鍵也可作為錄音切換鍵。</Note>

## 自訂

切換 UI 元素的可見性 <sup>Pro</sup>：

- 快捷鍵設定
- 轉錄預覽
- 輸出確認（提示通知）
- 複製上次按鈕
- 輸入（麥克風）選擇器
- 模型切換器
- 轉錄速度顯示

## 資料

- **遙測**：切換匿名當機報告和使用統計（永不收集音訊或文字）
- **取得資料**：GDPR 資料匯出（每 30 天一次）
- **刪除帳號**：匿名化您的帳號資料並登出
- **法律**：服務條款和隱私政策連結

## 關於

檢視目前應用程式版本、檢查更新，以及存取網站、支援、文件和 Discord 的快速連結。
