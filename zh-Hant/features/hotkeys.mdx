# 快捷鍵

使用可自訂的鍵盤快捷鍵控制 Echophrase。

## 預設快捷鍵

| 動作 | 預設快捷鍵 |
|------|-----------|
| **按住說話** | `Ctrl+Shift+Space` |
| **切換錄音** | `Ctrl+Shift+R` |
| **取消錄音** | `Escape` |

## 自訂快捷鍵

1. 開啟 Echophrase 設定
2. 前往**快捷鍵**
3. 點擊任一快捷鍵進行更改
4. 按下您想要的組合鍵

## 小提示

- 選擇不會與其他應用程式衝突的快捷鍵
- 建議大多數使用者使用「按住說話」模式
- 「切換」模式適合較長的聽寫場景
