# 快捷鍵

使用可自訂的鍵盤快捷鍵控制 Echophrase。

## 預設快捷鍵

### Windows 與 Linux

| 動作 | 預設快捷鍵 |
|------|-----------|
| **按住說話** | `Ctrl+Shift+Space` |
| **切換錄音** | `Ctrl+Shift+R` |
| **取消錄音** | `Escape` |

### macOS

在 macOS 上，預設的錄音快捷鍵是專用的**聽寫鍵**（Dictation key）- 即帶有麥克風圖示的按鍵（在多數 Apple 鍵盤上為 F5）。

| 動作 | 預設快捷鍵 |
|------|-----------|
| **錄音（按住說話／切換）** | 聽寫鍵（麥克風圖示，顯示為 `F5`） |
| **取消錄音** | `Escape` |

<Note>
當聽寫鍵被綁定時，Echophrase 會接管它，因此按下該鍵會啟動 Echophrase，而非 macOS 內建的聽寫功能。首次使用時，macOS 可能會要求「輔助使用／輸入監控」權限。若您將快捷鍵改綁為其他按鍵，聽寫鍵會恢復其原本的 macOS 行為。
</Note>

## 自訂快捷鍵

1. 開啟 Echophrase 設定
2. 前往**快捷鍵**
3. 點擊任一快捷鍵進行更改
4. 按下您想要的組合鍵

## 小提示

- 選擇不會與其他應用程式衝突的快捷鍵
- 建議大多數使用者使用「按住說話」模式
- 「切換」模式適合較長的聽寫場景
