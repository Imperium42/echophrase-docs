# 離線使用

Echophrase 設計為可離線運作。Echophrase 免費且開源，轉錄**100% 離線且無限制使用** - 無需帳號、無需網路連線，永遠如此。轉錄本身完全不需要網路 - 音訊在您的 GPU 上本地處理，您的語音永遠不會離開您的裝置。

<Note>
**唯一的例外是首次執行。** 模型採需求下載，因此您需要連網一次，以取得想使用的模型。
該模型下載到本機後，轉錄就再也不會連上網路。預設的 Parakeet-TDT 0.6B v3 約 2.5 GB，
其他模型請參閱[模型選擇](/zh-Hant/config/models)。
</Note>

<Note>
**遙測呢？** 與轉錄無關，Echophrase 在官方建置版本中預設會收集匿名、無法識別個人身分的使用遙測資料（從原始碼建置的版本不會傳送任何資料）-
例如 GPU 後端、選用的模型，以及設定／工作階段事件，還有當機報告 - 但絕不包含
音訊或轉錄內容。首次啟動時，同意選項預設勾選，但每個事件都遵守您的回答，您可隨時於
「設定 > 資料 > 傳送匿名應用程式統計」退出（或以 `DO_NOT_TRACK=1` 啟動）。完整的逐項事件
清單請見[我們收集哪些資料](/zh-Hant/privacy/telemetry)。無論是否連網（包含飛航模式），
轉錄運作方式完全相同 - 沒有網路也就沒有資料可傳送。
</Note>

沒有任何需要驗證的東西：Echophrase 沒有帳號、沒有登入、沒有授權檢查、也沒有到期日。轉錄永遠不會連線任何伺服器，因此不存在任何「上線要求」。**離線、永遠、直接就能用。**

## 哪些情況需要連線網路

只有少數幾件事會用到網路，且都不會接觸您的音訊或轉錄文字：

- 下載您選擇的模型（來自 Hugging Face），每個模型一次
- 啟動時的更新檢查（直接連線更新 CDN）
- 匿名應用程式統計，僅限官方建置版本，且僅在您允許時傳送

其餘一切 - 轉錄、快捷鍵、設定、游標處貼上、在已下載的模型間切換 - 都完全不需要網路。
