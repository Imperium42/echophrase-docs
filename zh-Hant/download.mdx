# 下載 Echophrase

取得適用於您平台的最新版本。

## 系統需求

| 平台 | 最低需求 | 建議配備 |
|------|---------|---------|
| **Windows** | Windows 10+ | Windows 11 |
| **macOS** | macOS 12+ | macOS 14+ |
| **Linux** | Ubuntu 22.04+ | Ubuntu 24.04+ |
| **記憶體** | 4 GB | 8 GB+ |
| **GPU** | 無（CPU 即可） | Windows 上的 DirectX 12 GPU；macOS 上的 Apple Silicon（Metal — *測試中*） |

## GPU 加速

Echophrase 會在首次啟動時自動偵測最快的可用裝置 — 您無需進行任何設定，
也不需要安裝任何驅動程式。

- **Windows**：在任何 DirectX 12 GPU（NVIDIA、AMD、Intel、Qualcomm）上
  使用 DirectML。內建於 Windows，無需安裝。
- **macOS**：在 Apple Silicon、macOS 13.3+ 上使用 Metal 加速 — 目前
  **測試中**。
- **Linux**：CPU。GPU 加速已列入規劃。

請參閱[系統需求](/zh-Hant/requirements)以查看硬體建議與模型支援表格。
我們已不再支援 CUDA — 該頁面說明了我們做出此決定的原因。
