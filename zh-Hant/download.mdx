# 下載 Echophrase

取得適用於您平台的最新版本。

## 系統需求

| 平台 | 最低需求 | 建議配備 |
|------|---------|---------|
| **Windows** | Windows 10+ | Windows 11 |
| **macOS** | macOS 12+ | macOS 14+ |
| **Linux** | Ubuntu 22.04+ | Ubuntu 24.04+ |
| **記憶體** | 4 GB | 8 GB+ |
| **GPU** | — | NVIDIA（支援 CUDA 12+） |

## GPU 加速（選用）

如需更快的轉錄速度，請安裝 NVIDIA CUDA：

- **CUDA**：12.0 或更新版本
- **cuDNN**：9.5.1 或更新版本

詳細說明請參閱 [GPU 設定](/zh-Hant/config/gpu)。
