# 下載 Echophrase

Echophrase 免費且開源。取得適用於您平台的最新版本 - 無需帳號或授權金鑰。

## 系統需求

| 平台 | 最低需求 | 建議配備 |
|------|---------|---------|
| **Windows** | Windows 11（Windows 10 或可執行，但不在官方支援範圍） | Windows 11 |
| **macOS** | macOS 13.3+（僅 Apple Silicon） | macOS 14+ |
| **Linux** | 社群支援，需從原始碼建置（僅 CPU） | - |
| **記憶體** | 8 GB | 16 GB |
| **GPU** | 無（CPU 即可） | Windows 上的 DirectX 12 GPU；macOS 上的 Apple Silicon（Metal） |

最新版本可於 [echophrase.com/download](https://echophrase.com/download) 取得，會自動偵測您的平台。

Windows 與 macOS 版本皆已完成程式碼簽署，macOS 版本並已通過 Apple 公證，因此 macOS 安裝時無需任何
Gatekeeper 繞過步驟。Windows 上的新版本仍可能出現 SmartScreen 提示：點選**其他資訊**，再點選**仍要執行**。Echophrase 會自動更新（透過 winget、Scoop 或
Homebrew 安裝的版本則改由對應的套件管理工具更新）。

<Note>
**為什麼 Echophrase 不在 Mac App Store 上架？** App Store 應用程式必須在 Apple 的沙盒中執行，
而沙盒會阻擋 Echophrase 將轉錄文字貼到其他應用程式所需的輔助使用權限。自動貼上是核心功能，
因此 Echophrase 在商店之外發行，並經過簽署與公證。
</Note>

## Linux（社群支援）

**沒有官方 Linux 下載。** Linux 為社群支援且僅支援 CPU：請依照儲存庫中的
[建置說明](https://github.com/Imperium42/echophrase#build-from-source)從原始碼建置。
歡迎提交改進 Linux 支援的 pull request。視桌面環境而定，全域快捷鍵綁定可能無法使用 -
若是如此，請改用「開放麥克風」模式（設定 → 音訊輸入）。

## GPU 加速

Echophrase 會在首次啟動時自動偵測最快的可用裝置 - 您無需進行任何設定，
也不需要安裝任何驅動程式。

- **Windows**：在任何 DirectX 12 GPU（NVIDIA、AMD、Intel、Qualcomm）上
  使用 DirectML。DirectML 執行階段隨應用程式一併提供，無需安裝。
- **macOS**：在 Apple Silicon、macOS 13.3+ 上使用 CoreML/Metal 加速。
- **Linux**：僅支援 CPU。

請參閱[系統需求](/zh-Hant/requirements)以查看硬體建議與模型支援表格。
