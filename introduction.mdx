# Welcome to Echophrase

Echophrase is a **privacy-first desktop application** that transforms your voice into text using state-of-the-art AI - all processed locally on your machine.

## Why Echophrase?

<CardGroup cols={2}>
  <Card title="100% Private" icon="lock">
    Your voice never leaves your computer. No cloud processing, no data collection.
  </Card>
  <Card title="Swap the Engine, Keep the App" icon="microphone">
    Swappable transcription backends built on a trait-based architecture. Ships with **NVIDIA Parakeet-TDT 0.6B v3** by default; Whisper, Distil-Whisper, and other models are also supported.
  </Card>
  <Card title="Fast, Native, Cross-Platform" icon="feather">
    Built on Tauri + Rust, not Electron. A lightweight, genuinely native app on Windows, macOS, and Linux with a tiny footprint and instant startup.
  </Card>
  <Card title="GPU Accelerated" icon="bolt">
    Fast on-device transcription via DirectML on Windows, Metal on macOS, with CPU fallback everywhere.
  </Card>
  <Card title="Works Anywhere" icon="keyboard">
    Type in any application - browsers, editors, chat apps, you name it.
  </Card>
  <Card title="Grammar & Punctuation Cleanup (Pro)" icon="wand-magic-sparkles">
    Optional transform models automatically clean up grammar and punctuation, something many competitors leave entirely to you.
  </Card>
  <Card title="Save to File & JSON Export (Pro)" icon="file-export">
    Auto-save transcripts to a file, or export as JSON with custom metadata for downstream tooling.
  </Card>

  </Card>
</CardGroup>

Plus tons of quality-of-life customizations, from hotkeys to filler-word removal to number normalization - see [Configuration](/config/settings).

## How It Works

1. **Press a hotkey** to start recording
2. **Speak naturally** - Echophrase listens
3. **Release** and your words appear as text, typed wherever your cursor is

No copy-paste. No switching windows. Just speak and it types.
