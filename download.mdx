# Download Echophrase

Echophrase is free and open source. Get the latest version for your platform - no account or license key needed.

## System Requirements

| Platform | Minimum | Recommended |
|----------|---------|-------------|
| **Windows** | Windows 11 (Windows 10 may work, not officially supported) | Windows 11 |
| **macOS** | macOS 13.3+ (Apple Silicon only) | macOS 14+ |
| **Linux** | Community-supported, build from source (CPU only) | - |
| **RAM** | 8 GB | 16 GB |
| **GPU** | None (CPU works) | DirectX 12 GPU on Windows; Apple Silicon (Metal) on macOS |

Windows and macOS builds are code-signed, and macOS builds are notarized with
Apple, so macOS installs without Gatekeeper workarounds. On Windows, SmartScreen
may still show a prompt for a new release: click **More info**, then **Run
anyway**. Echophrase
updates itself (installs from winget, Scoop, or Homebrew update through that
package manager instead).

<Note>
**Why isn't Echophrase on the Mac App Store?** App Store apps must run in
Apple's sandbox, and the sandbox blocks the Accessibility permission Echophrase
needs to paste your transcript into other apps. Auto-paste is the core feature,
so Echophrase ships outside the store, signed and notarized instead.
</Note>

## Linux (community-supported)

There are **no official Linux downloads**. Linux is community-supported and
CPU-only: build it from source by following the
[build instructions](https://github.com/Imperium42/echophrase#build-from-source)
in the repository. Pull requests that improve Linux support are welcome. Global
hotkey bindings may be unavailable depending on your desktop environment - use
Open Mic mode instead (Settings -> Audio Input) if so.

## GPU Acceleration

Echophrase auto-detects the fastest available device on first launch - you
don't need to configure anything, and there's no driver setup to do.

- **Windows**: DirectML on any DirectX 12 GPU (NVIDIA, AMD, Intel, Qualcomm).
  The DirectML runtime ships bundled with the app, no install required.
- **macOS**: CoreML/Metal acceleration on Apple Silicon, macOS 13.3+.
- **Linux**: CPU only.

See [Requirements](/requirements) for hardware recommendations and the model
support matrix.
