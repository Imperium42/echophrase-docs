---
title: No Telemetry
description: Echophrase has no telemetry and no analytics. Its only network traffic is model downloads and update checks.
---

Echophrase has **no telemetry and no analytics**. It sends no usage stats, no crash reports, and no install counts. No accounts exist, and no audio or text ever leaves your device.

The only network traffic the app makes:

| Destination | When | What is sent |
|------|------|------|
| `huggingface.co` | You pick a model, or use one for the first time | A request for the model file |
| `cdn.crabnebula.app` | Update check (official builds) | Current version, platform, and CPU architecture |

<Note>
Older versions (before this change) could send anonymous usage stats if you allowed it. Updating to the latest version removes that entirely.
</Note>

See [Privacy & Data](/privacy) for the full picture.
