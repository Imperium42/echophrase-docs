# Hotkeys

Control Echophrase with customizable keyboard shortcuts.

## Default Hotkeys

### Windows & Linux

| Action | Default Shortcut |
|--------|------------------|
| **Start / stop recording** | `Ctrl+Shift+Space` |
| **Cancel recording** | `Escape` |

Echophrase binds a single global recording hotkey. It starts recording on the
first press and stops (and transcribes) on the second.

### macOS

On macOS the default recording hotkey is the dedicated **Dictation key** - the
key with the microphone icon (F5 on most Apple keyboards).

| Action | Default Shortcut |
|--------|------------------|
| **Start / stop recording** | Dictation key (mic icon, shown as `F5`) |
| **Cancel recording** | `Escape` |

<Note>
Echophrase takes over the Dictation key while it's bound, so pressing it starts
Echophrase instead of macOS's built-in dictation. The first time you use it,
macOS may ask for Accessibility/Input Monitoring permission. If you rebind the
hotkey to something else, the Dictation key reverts to its normal macOS behavior.
</Note>

## Customizing Hotkeys

1. Open Echophrase settings
2. Navigate to **Hotkeys**
3. Click on any shortcut to change it
4. Press your desired key combination

## Tips

- Choose shortcuts that don't conflict with your other applications
- Push-to-Talk is recommended for most users; switch to Open Mic under
  Settings -> Audio Input for longer hands-free sessions
- `Escape` and `Space` also toggle recording when the app window is focused
