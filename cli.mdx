# CLI

Echophrase has a small command-line tool, `echophrase-cli`. It gives you terminal access to microphone recording and
audio transcoding without opening the app window, plus an [MCP server mode](/mcp)
so AI agents like Claude Code can drive voice capture directly.

## Where to find it

The CLI is not bundled with the desktop app installer yet: build it from the
[Echophrase source](https://github.com/Imperium42/echophrase/tree/main/cli). With a Rust toolchain installed, run this in
the repo root (on Linux, install `libasound2-dev` first):

```bash
cargo install --path cli
echophrase-cli --help
```

`cargo install` puts `echophrase-cli` in `~/.cargo/bin`, which is on your `PATH`
after a standard Rust install.

<Note>
Up to v1.0.1 the binary was named `echophrase`. It was renamed so it can never
overwrite the desktop app's own `echophrase` binary when both are built from the
same repo. See [ADR 0007](/developers/decisions/0007-cli-binary-name).
</Note>

## Commands

| Command | What it does |
|---------|--------------|
| `record` | Start recording the microphone in the background |
| `stop` | Stop the active recording and finalize the WAV file |
| `status` | Show whether a recording is currently in progress |
| `transcode` | Convert an existing WAV file to 16 kHz mono (downmix + resample + normalize) |
| `transcribe` | Transcribe a WAV file using the running desktop app's loaded model |
| `mcp` | Run as an MCP server so AI agents can drive voice capture |

## What each command needs

**Work standalone, no app required:**

- `record` / `stop` / `status`: capture the microphone in the background and
  write a WAV file to disk.
- `transcode`: normalizes an existing WAV file to the 16 kHz mono format the
  transcription pipeline expects. Works fully offline.

**Requires the desktop app:**

- `transcribe`: sends a WAV file to the already-running desktop app over a
  localhost-only connection and prints back the transcript. This needs:
  1. The Echophrase desktop app running
  2. The **MCP Server** toggle enabled in Settings (off by default)

  <Note>
  If the app is not running, `transcribe` exits with: `The Echophrase desktop
  app must be running to transcribe. Start the app and try again.`
  </Note>

## Quick examples

```bash
# Record, then stop and finalize
echophrase-cli record
echophrase-cli status
echophrase-cli stop

# Normalize an existing recording
echophrase-cli transcode meeting.wav

# Transcribe (desktop app running, MCP Server enabled)
echophrase-cli transcribe meeting.16k.wav
```

Every command has its own detailed help, for example `echophrase-cli record --help`.
