## 您的语音永远不会离开您的电脑

转录**完全在您的设备上运行**。麦克风音频与生成的文字都由本机 GPU 上运行的 AI 模型处理 - 任何音频或转录文字都不会被上传、串流或发送到任何服务器。

这项保证针对的是您的音频与文字，而非指应用程序完全不使用网络。Echophrase 也会下载您选择的模型、检查更新、在您登录时同步权益，并默认发送匿名的应用程序统计数据（可在下方选择退出）。这些请求都不包含音频或转录文字 - 完整的主机列表见[下方](#应用程序会连接的主机)。

<Card title="我们永远看不到您的语音或文字" icon="shield-halved">
  录音会在转录后立即删除。转录文字仅存在于您的剪贴板或文件中 - 我们完全无法访问。这里没有「云端处理」选项，这是刻意的设计。
</Card>

## 我们「不」收集的数据

| 数据 | 是否收集？ |
|------|-----------|
| 语音录音 | **从不** |
| 转录文字 | **从不** |
| 音频文件 | **从不** |
| AI 模型的输入或输出 | **从不** |
| IP 地址 | **从不保存** |
| 设备指纹 | **从不** |
| Cookie | **无** |

## 应用程序会连接的主机

转录本身永远不会使用网络。以下是桌面应用程序会连接的所有主机 - 欢迎用抓包工具自行验证：

| 目的地 | 时机 | 是否包含音频或文字？ |
|------|------|------|
| `huggingface.co` | 下载您选择的模型 | 否 |
| `cdn.crabnebula.app` | 启动时检查更新 | 否 |
| `api.echophrase.com` | 启动时的健康检查；登录与订阅检查（仅在您登录时才会发送账号数据） | 否 |
| `telemetry.echophrase.com` | 匿名应用程序统计数据，默认开启（见下方） | 否 |
| `www.google.com`、`one.one.one.one` | 空的网络连接探测 | 否 |
| `fonts.googleapis.com`、`fonts.gstatic.com` | 应用程序窗口的表情符号网页字体 | 否 |

## 我们收集的数据

我们收集**匿名、无法识别个人身份的遥测数据**，用于做出更好的产品决策 - 例如用户采用哪些 GPU 后端、哪些 AI 模型最受欢迎，以及最佳的默认设置应该是什么。这些数据都不会与用户 ID 或账号链接。

### 同意与退出

Echophrase 会在首次启动时询问（选项默认勾选），且**每个事件都遵守您的回答** - 包含安装数统计。您可随时于「**设置 > 数据 > 发送匿名应用程序统计**」变更：一个开关，没有确认弹窗。系统会送出最后一个事件以确认退出，之后所有追踪即停止。以 `DO_NOT_TRACK=1`（或 `ECHOPHRASE_NO_TELEMETRY=1`）启动则完全覆写该设置。关闭遥测不会影响任何应用程序功能。

## 账号数据

若您选择登录（可选 - 应用程序在没有账号的情况下完全可用），我们会保存：

- **电子邮件**（通过 Supabase OAuth）用于账号识别
- **订阅方案**用于功能访问
- **付款信息**完全由 Paddle 处理（我们永远看不到您的卡片数据）
- **应用程序设置**，仅在您是 Pro 订阅者并于各设备明确激活云端同步时（设置 > 云端同步）。仅同步设置 - 绝不包含音频或转录内容。

### GDPR 与数据权利

您可于「**设置 > 数据**」导出或删除所有数据。数据导出功能有速率限制，每 30 天仅能使用一次；账号删除（匿名化）请求则会在另外的 30 天服务水准内处理完成。这是两个不同动作各自独立的 30 天期间。关于数据保存、第三方服务，以及您在 GDPR/CCPA 下的权利，详见完整的[隐私政策](https://echophrase.com/privacy)。
