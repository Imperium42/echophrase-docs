# 快速入门

只需几个步骤，即可在您的电脑上启动 Echophrase。无需注册 - 免费方案无限制使用，首次启动一次性下载模型后即可 100% 离线转录。

## 1. 下载与安装

从[下载页面](/zh-CN/download)下载适用于您平台的最新版本。

## 2. 启动 Echophrase

从应用程序菜单打开 Echophrase。首次启动时，它会下载默认 AI 模型（Parakeet-TDT 0.6B v3，约 2.5 GB）。

## 3. 授予麦克风访问权限

系统提示时，请允许 Echophrase 访问您的麦克风。您的音频会在本地处理 - 不会发送到云端。

## 4. 开始转录

1. 在任何文字字段中点击（浏览器、编辑器、聊天软件）
2. 按下录音快捷键 - **ctrl+shift+space**（Windows/Linux）或 **F5**（Mac，即听写键，麦克风图标）
3. 自然说话
4. 再按一次快捷键停止 - 您的话语会以文字形式出现

就这么简单！您已准备就绪。
