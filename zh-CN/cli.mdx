# CLI

Echophrase 提供一个小型命令行工具 `echophrase-cli`。
它让您无需打开应用程序窗口即可在终端机中录制麦克风音频、转换音频格式，
并提供 [MCP 服务器模式](/zh-CN/mcp-server)，让 Claude Code 等 AI 代理可以直接驱动语音截取。

## 在哪里找到它

CLI 目前尚未随桌面应用程序安装包提供，请从 [Echophrase 源代码](https://github.com/Imperium42/echophrase/tree/main/cli) 自行构建。
安装好 Rust 工具链后，在源代码根目录运行（Linux 需先安装 `libasound2-dev`）：

```bash
cargo install --path cli
echophrase-cli --help
```

`cargo install` 会把 `echophrase-cli` 放到 `~/.cargo/bin`，标准 Rust 安装会将其加入 `PATH`。

<Note>
v1.0.1（含）以前此可执行文件名为 `echophrase`。为了避免在同一份源代码中构建时覆盖桌面应用程序本身的
`echophrase` 可执行文件，已更名。详见 [ADR 0007](/developers/decisions/0007-cli-binary-name)。
</Note>

## 指令

| 指令 | 功能 |
|------|------|
| `record` | 在背景开始录制麦克风 |
| `stop` | 停止目前的录音并完成 WAV 文件 |
| `status` | 显示目前是否正在录音 |
| `transcode` | 将现有 WAV 文件转换为 16 kHz 单声道（降混、重采样、范式） |
| `transcribe` | 使用运行中桌面应用程序已加载的模型转录 WAV 文件 |
| `mcp` | 以 MCP 服务器模式运行，让 AI 代理可以驱动语音截取 |

## 各指令的需求

**可独立运作，不需要应用程序：**

- `record` / `stop` / `status`：在背景截取麦克风并将 WAV 文件写入磁盘。
- `transcode`：将现有 WAV 文件范式为转录流程所需的 16 kHz 单声道格式。完全离线运作。

**需要桌面应用程序：**

- `transcribe`：通过仅限本机的连接将 WAV 文件发送给已在运行的桌面应用程序，
  并返回转录文字。需要：
  1. Echophrase 桌面应用程序正在运行
  2. 在设置中激活 **MCP 服务器**开关（默认关闭）

  <Note>
  若应用程序未运行，`transcribe` 会结束并显示：「The Echophrase desktop
  app must be running to transcribe. Start the app and try again.」
  </Note>

## 快速范例

```bash
# 錄音，然後停止並完成
echophrase-cli record
echophrase-cli status
echophrase-cli stop

# 范式化现有录音
echophrase-cli transcode meeting.wav

# 转录（需要桌面应用程序运行中、已激活 MCP 服务器）
echophrase-cli transcribe meeting.16k.wav
```

每个指令都有各自的详细说明，例如 `echophrase-cli record --help`。
