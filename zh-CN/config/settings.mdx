# 设置

从主窗口的齿轮图标打开设置。设置分为以下几个区块。

## 账号

登录完全是可选的，仅在需要 Pro 功能时才需要 - 免费方案完全离线即可转录，无需账号。若您选择登录，可查看您的电子邮件、已链接的提供者（Google、email）以及目前的方案等级。您可以输入授权密钥、链接其他登录方式，或注销。

## 音频输入

- **输入设备**：选择您的麦克风，或维持系统默认
- **录音模式**：**按住说话**（默认）或**开放式麦克风** - 请参阅
  [输入模式](/zh-CN/features/modes)
- **开放式麦克风阈值**（0-100%）：仅在**开放式麦克风**模式下显示。决定开放式麦克风
  开始录音所需的最小语音音量。使用**测试**按钮查看实时音量计。超过 80% 会变红并
  提示警告，因为过高的阈值可能会漏掉轻声或较小声的开头。

## 录音

- **最长持续时间**：每次录音 5 秒-5 分钟（默认 30 秒；所有方案上限相同，且无需
  账号即可调整）。滑杆在超过 1 分钟后会由绿转黄再转红 - 因为转录并非实时串流，
  录音越长，处理所需时间也越长，且在完成前不会显示任何内容。
- **移除填充词**：过滤「嗯」、「啊」等语助词 <sup>Pro</sup>
- **数字范式**：将「三」转换为「3」 <sup>Pro</sup>
- **为未完成的句子附加空格**：当转录文字未以 `.`、`!` 或 `?` 结尾时附加一个尾随空格，让你可以在句子中途暂停并继续听写，而不必手动加空格（默认打开）

## 快捷键

设置切换录音的全局快捷键。默认：在 Windows/Linux 上为 **Ctrl+Shift+Space**，在 macOS 上为**听写键**（麦克风图标，显示为 F5）。点击绑定进入截取模式，然后按下您想要的组合键。ESC 取消。

<Note>当应用程序窗口处于焦点时，ESC 和空白键也可作为录音切换键。</Note>

## 语音模型

查看和更换使用中的转录模型。显示您的 GPU/设备信息、目前模型名称、大小和质量评等。点击**更换**以浏览和下载其他模型。

<Note>可用模型取决于您的方案等级。请参阅 [Beta 页面](/zh-CN/beta)的比较表。</Note>

## 自定义模型 <sup>Pro</sup>

自带您自己的 ONNX 转录模型 - 导入本机的 `.onnx` 文件，或直接从 HuggingFace 仓库网址下载。Echophrase 会在切换前验证模型。支持的格式与模型来源请参阅[自定义模型](/zh-CN/features/custom-models)。

## 转换模型 <sup>Pro</sup>

激活可选的后处理步骤，对转录结果进行语法与标点校正。使用轻量级的 **T5-Mini Grammar** 模型（约 60 MB），依需求下载并完全在设备上运行。此为 **Pro 专属**功能，免费方案的开关为锁定状态。您可以撰写自定义转换规则，或使用默认的语法校正。

## GPU 加速

Echophrase 会在运行时自动检测最快的可用运行提供者。**自动（推荐）**选项
会为您的硬件选择最佳设备：任何 Windows DirectX 12 GPU 上的 DirectML、
Apple Silicon 上的 CoreML，或 Copilot+ PC 上的 NPU。当没有
其他选项可用时，CPU 是后备方案。

如有需要，您可以强制使用特定的提供者：

- **自动（推荐）**：让 Echophrase 在工作阶段开始时选择最快的设备
- **DirectML**：强制使用 Windows DirectML（任何 DirectX 12 GPU）
- **CoreML**：强制使用 Apple Metal（Apple Silicon 上的 macOS 13.3+）
- **CUDA**（Windows、NVIDIA、选用）：下载 CUDA 插件并强制使用 CUDA 提供者 - 需要 CUDA Toolkit 13.0+ 与 cuDNN 9.19+，并须重新启动
- **CPU**：强制使用 CPU - 适合节省电力或 GPU 忙于其他工作时

<Note>DirectML 在 Windows 上涵盖 NVIDIA GPU，无需手动对齐驱动程序 /
Toolkit 版本，因此为默认值。已安装 CUDA 13.0+ 与 cuDNN 9.19+ 的 NVIDIA
用户，可在此选择下载并激活 CUDA 插件。详见
[GPU 加速](/zh-CN/config/gpu)。</Note>

<Note>变更使用中的提供者需要重新启动 Echophrase 才会生效。当变更需要重新启动时，设置界面会显示「重新启动以套用」横幅。</Note>

## 输出

控制转录完成后的行为。

- **格式**：纯文字（所有方案）、带自定义元数据模板的 JSON <sup>Pro</sup>
- **录音后动作**（可选择一或多项）：
  - 复制到剪贴板（默认）
  - 贴在光标处（所有方案皆免费，但需要登录 - 这是免费方案中唯一需要账号、而非需要
    Pro 的输出动作；其他所有免费方案功能，包括转录本身，完全不需要账号）
  - 保存为文件 <sup>Pro</sup> - 设置自动保存目录并导出转录结果，包括带自定义元数据的 JSON <sup>Pro</sup>

## 语言

选择 UI 语言。目前支持：**英语**和**繁体中文**。

## 自定义

切换 UI 元素的可见性 <sup>Pro</sup>：

- 快捷键设置
- 转录预览
- 输出确认（提示通知）
- 复制上次按钮
- 输入（麦克风）选择器
- 模型切换器
- 转录速度显示

## 无障碍

依照您的偏好缩放整个界面 - 适合高 DPI 显示器，或默认字体太小难以阅读时使用。

- **界面缩放 - 自动**（默认）：跟随操作系统的显示缩放设置（例如 Windows 的 150% 缩放）
- **界面缩放 - 手动**：使用滑杆设置 **50% 到 200%** 之间的任何比例，变更实时套用
- **随窗口大小缩放界面**：可选择在调整窗口大小时同步缩放界面

<Note>在少数无法可靠检测系统缩放的环境中，自动模式会回退到 100%，应用程序会建议切换至手动模式。</Note>

## 云端同步 <sup>Pro</sup>

可依设备选择性激活，将应用程序设置同步至我们的服务器，让设置跟着您在每一台登录的
设备上。默认为关闭。仅同步设置 - 语音数据、音频与转录内容永不同步，API 密钥、
硬件设置与本机文件路径也不会同步。您可随时将本机设置上传，或把服务器上的版本拉下来。

## MCP 服务器 <sup>Pro</sup>

激活此开关，让 AI 代理（例如 Claude Code）可以通过
[CLI 的 MCP 服务器](/zh-CN/mcp)模式操作 Echophrase 的录音与转录功能。
默认关闭，需要有效的 Pro 订阅。桌面应用程序必须在整个代理工作阶段中保持运行，
因为它拥有已加载的转录模型。完整的工具清单与设置方式请参阅
[CLI](/zh-CN/cli) 与 [MCP 服务器](/zh-CN/mcp)。

## 数据

- **发送匿名应用程序统计**：切换匿名崩溃报告和使用统计（永不收集音频或文字）。首次启动时询问，默认勾选；每个事件都遵守此设置，`DO_NOT_TRACK=1` 则会覆写它。详见[我们收集哪些数据](/zh-CN/privacy/telemetry)
- **取得数据**：GDPR 数据导出（速率限制为每 30 天一次）
- **删除账号**：匿名化您的账号数据并注销（于另一个独立的 30 天服务水准内处理完成 - 与上方的数据导出速率限制是不同的 30 天期间）
- **法律**：服务条款和隐私政策链接
