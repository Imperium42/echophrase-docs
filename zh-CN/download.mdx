# 下载 Echophrase

Echophrase 免费且开源。取得适用于您平台的最新版本 - 无需账号或授权密钥。

## 系统需求

| 平台 | 最低需求 | 建议配备 |
|------|---------|---------|
| **Windows** | Windows 11（Windows 10 或可运行，但不在官方支持范围） | Windows 11 |
| **macOS** | macOS 13.3+（仅 Apple Silicon） | macOS 14+ |
| **Linux** | 社区支持，需从源代码构建（仅 CPU） | - |
| **内存** | 8 GB | 16 GB |
| **GPU** | 无（CPU 即可） | Windows 上的 DirectX 12 GPU；macOS 上的 Apple Silicon（Metal） |

Windows 与 macOS 版本皆已完成代码签署，macOS 版本并已通过 Apple 公证，因此 macOS 安装时无需任何
Gatekeeper 绕过步骤。Windows 上的新版本仍可能出现 SmartScreen 提示：点击**更多信息**，再点击**仍要运行**。Echophrase 会自动更新（通过 winget、Scoop 或
Homebrew 安装的版本则改由对应的包管理器更新）。

<Note>
**为什么 Echophrase 不在 Mac App Store 上架？** App Store 应用程序必须在 Apple 的沙盒中运行，
而沙盒会阻挡 Echophrase 将转录文字粘贴到其他应用程序所需的辅助功能权限。自动粘贴是核心功能，
因此 Echophrase 在商店之外发行，并经过签署与公证。
</Note>

## Linux（社区支持）

**没有官方 Linux 下载。** Linux 为社区支持且仅支持 CPU：请按照仓库中的
[构建说明](https://github.com/Imperium42/echophrase#build-from-source)从源代码构建。
欢迎提交改进 Linux 支持的 pull request。视桌面环境而定，全局快捷键绑定可能无法使用 -
若是如此，请改用「开放麦克风」模式（设置 → 音频输入）。

## GPU 加速

Echophrase 会在首次启动时自动检测最快的可用设备 - 您无需进行任何设置，
也不需要安装任何驱动程序。

- **Windows**：在任何 DirectX 12 GPU（NVIDIA、AMD、Intel、Qualcomm）上
  使用 DirectML。DirectML 运行时随应用程序捆绑提供，无需安装。
- **macOS**：在 Apple Silicon、macOS 13.3+ 上使用 CoreML/Metal 加速。
- **Linux**：仅支持 CPU。

请参阅[系统需求](/zh-CN/requirements)以查看硬件建议与模型支持表格。
