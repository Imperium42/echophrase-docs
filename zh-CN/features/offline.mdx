# 离线使用

Echophrase 设计为可离线运作。Echophrase 免费且开源，转录**100% 离线且无限制使用** - 无需账号、无需网络连接，永远如此。转录本身完全不需要网络 - 音频在您的 GPU 上本地处理，您的语音永远不会离开您的设备。

<Note>
**唯一的例外是首次运行。** 模型采需求下载，因此您需要连网一次，以取得想使用的模型。
该模型下载到本机后，转录就再也不会连上网络。默认的 Parakeet-TDT 0.6B v3 约 2.5 GB，
其他模型请参阅[模型选择](/zh-CN/config/models)。
</Note>

<Note>
**遥测呢？** 与转录无关，Echophrase 在官方构建版本中默认会收集匿名、无法识别个人身份的使用遥测数据（从源代码构建的版本不会发送任何数据）-
例如 GPU 后端、选用的模型，以及设置／工作阶段事件，还有崩溃报告 - 但绝不包含
音频或转录内容。首次启动时，同意选项默认勾选，但每个事件都遵守您的回答，您可随时于
「设置 > 数据 > 发送匿名应用程序统计」退出（或以 `DO_NOT_TRACK=1` 启动）。完整的逐项事件
清单请见[我们收集哪些数据](/zh-CN/privacy/telemetry)。无论是否连网（包含飞行模式），
转录运作方式完全相同 - 没有网络也就没有数据可发送。
</Note>

没有任何需要验证的东西：Echophrase 没有账号、没有登录、没有授权检查、也没有到期日。转录永远不会连接任何服务器，因此不存在任何「上线要求」。**离线、永远、直接就能用。**

## 哪些情况需要连接网络

只有少数几件事会用到网络，且都不会接触您的音频或转录文字：

- 下载您选择的模型（来自 Hugging Face），每个模型一次
- 启动时的更新检查（直接连接更新 CDN）
- 匿名应用程序统计，仅限官方构建版本，且仅在您允许时发送

其余一切 - 转录、快捷键、设置、光标处粘贴、在已下载的模型间切换 - 都完全不需要网络。
