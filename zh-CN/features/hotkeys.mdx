# 快捷键

使用可自定义的键盘快捷键控制 Echophrase。

## 默认快捷键

### Windows 与 Linux

| 动作 | 默认快捷键 |
|------|-----------|
| **开始／停止录音** | `Ctrl+Shift+Space` |
| **取消录音** | `Escape` |

Echophrase 只绑定一个全局录音快捷键：第一次按下开始录音，再按一次即停止并转录。

### macOS

在 macOS 上，默认的录音快捷键是专用的**听写键**（Dictation key）- 即带有麦克风图标的按键（在多数 Apple 键盘上为 F5）。

| 动作 | 默认快捷键 |
|------|-----------|
| **开始／停止录音** | 听写键（麦克风图标，显示为 `F5`） |
| **取消录音** | `Escape` |

<Note>
当听写键被绑定时，Echophrase 会接管它，因此按下该键会启动 Echophrase，而非 macOS 内置的听写功能。首次使用时，macOS 可能会要求「辅助使用」权限（详见[权限说明](/zh-CN/troubleshooting/permissions) - Echophrase 从不要求「输入监控」权限）。若您将快捷键改绑为其他按键，听写键会恢复其原本的 macOS 行为。
</Note>

## 自定义快捷键

1. 打开 Echophrase 设置
2. 前往**快捷键**
3. 点击任一快捷键进行更改
4. 按下您想要的组合键

## 小提示

- 选择不会与其他应用程序冲突的快捷键
- 建议大多数用户使用「按键说话」模式；若需要较长时间的免持听写，可于
  「设置 → 音频输入」切换为「开放麦克风」
- 当应用程序窗口处于焦点时，`Escape` 与 `Space` 也可切换录音
