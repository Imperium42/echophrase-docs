# 系统需求

Echophrase 可在多种硬件上运行。默认模型针对中阶游戏 GPU 调校；另有更轻量的
「Lite」变体，可在没有独立 GPU 的设备上顺畅运作。

## 系统

| 资源 | 最低需求 | 建议配备 |
|------|---------|---------|
| **操作系统** | Windows 11（Windows 10 或可运行，但不在官方支持范围） | Windows 11 |
| **macOS** | macOS 13.3（仅限 Apple Silicon） | macOS 14+ |
| **Linux** | 社区支持，需从源代码构建（仅 CPU） | - |
| **内存** | 8 GB | 16 GB |
| **磁盘空间** | 4 GB 可用（默认模型约 2.5 GB） | 8 GB 可用 |
| **GPU** | 无 - CPU 即可 | Windows 上的 DirectX 12 GPU |

<Note>
**Linux 为社区支持。** 没有官方 Linux 下载：请从源代码构建（仅 CPU，无 GPU 加速）。
Linux 上的全局快捷键可能无法使用，请改用「开放麦克风」模式。
Windows 与 macOS 才是官方、已完成代码签署的版本。详见[下载页面](/zh-CN/download)。
</Note>

## GPU 加速

Echophrase 会在首次启动时自动检测最快的可用设备 - 无需任何设置。

| 平台 | 加速方式 | 所需条件 |
|------|---------|---------|
| **Windows** | DirectML | 任何 DirectX 12 GPU（NVIDIA、AMD、Intel、Qualcomm） |
| **macOS** | CoreML / Metal | Apple Silicon，macOS 13.3+ |
| **Linux** | CPU | 需从源代码构建 |

<Note>
Windows 上默认使用 DirectML：随应用程序捆绑提供（DirectML 1.15.4）、不分 GPU 品牌皆可运作（NVIDIA、AMD、Intel、Qualcomm），
除了一般的显卡驱动程序外无需其他安装。没有 CUDA 路径。详见 [GPU 加速](/zh-CN/config/gpu)。
</Note>

## 支持的模型

以下数据直接来自桌面应用程序的模型登录表 - 这就是目前实际出货的模型。

| 模型 | 参数量 | 最低 VRAM | 建议 GPU | 实时速度 |
|------|--------|----------|----------|---------|
| **Parakeet-TDT 0.6B v3** *（默认）* | 0.6B | 6 GB | RTX 3080 或更佳 | 12× |
| **Qwen3-ASR 0.6B** *（国际多语言，52 种语言）* | 0.6B | 4 GB | RTX 3060 或更佳 | 2-6× |
| **Parakeet Lite** | 120M | 无（GPU 可选） | 任何现代 GPU，内置显卡亦可 | 2-5× |
| **T5-Mini Grammar** *（后处理）* | Mini | - | 任何 GPU | - |
